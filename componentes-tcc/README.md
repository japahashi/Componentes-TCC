# Componentes TCC

Projeto Vite + React + TypeScript.

## Rodando

```
npm install
npm run dev
```

Os componentes prontos ficam em `src/components`, cada um na sua pasta com `.tsx` e `.css`, exportados em `src/components/index.ts`. Detalhes de onde entram os ícones do Figma estão em `src/components/README.md`.

`src/pages/App.tsx` está renderizando `src/pages/ComponentsShowcase.tsx`, uma página em branco que só importa e mostra cada componente com dado de exemplo.
